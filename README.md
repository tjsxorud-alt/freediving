# 숨결 Freedive

프리다이빙 초보자가 훈련과 기록, 안전 체크를 한 곳에서 관리할 수 있는 정적 웹앱 MVP입니다.

## 주요 기능

- **CO₂ 테이블 타이머**: 준비 호흡, 숨 참기, 회복 호흡, 라운드 수를 설정해 인터벌 훈련을 진행합니다.
- **다이빙 로그북**: 날짜, 장소, 최대 수심, 다이브 시간, 메모를 브라우저 localStorage에 저장합니다.
- **안전 체크리스트**: 버디, 컨디션, 환경, 장비, 목표 수심을 입수 전에 확인합니다.

## 실행 방법

별도 빌드 과정이 필요 없습니다. 저장소 루트에서 정적 서버를 실행한 뒤 브라우저로 접속하세요.

```bash
python3 -m http.server 4173
```

이후 <http://localhost:4173>을 엽니다.

## 안전 고지

이 앱은 기록과 훈련 보조 도구이며 전문 교육, 자격 있는 버디, 현장 안전 판단을 대체하지 않습니다. 프리다이빙은 반드시 교육받은 환경에서 버디와 함께 진행하세요.
